# Inventory Management System

A C++ based Inventory Management System developed as an Object-Oriented Engineering Lab (OEL) project using Data Structures and Algorithms.

## Project Overview

This application helps manage product records, track stock levels, and maintain transaction history. It uses singly linked lists to store product and transaction records and provides different operations to manage inventory efficiently.

## Features

- Add new products
- Display all products
- Search products by ID
- Update product information
- Delete product records
- Sort products by ID, name, and quantity
- Perform stock-in and stock-out operations
- Maintain transaction history
- Generate low-stock reports
- Save and load product and transaction records using file handling

## Technologies Used

- **Programming Language:** C++
- **Data Structures:** Singly Linked Lists
- **Algorithms:** Linear Search and Bubble Sort
- **File Handling:** Text files (`products.txt` and `transactions.txt`)

## Files Included

- `main.cpp` – Main source code of the application
- `products.txt` – Stores product records
- `transactions.txt` – Stores transaction history

## How to Run

1. Download or clone this repository.
2. Open `main.cpp` in a C++ IDE or compiler.
3. Compile and run the program.
4. Use the menu to perform inventory operations.
